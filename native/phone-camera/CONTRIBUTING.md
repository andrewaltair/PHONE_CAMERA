# Contributing to MyCam

MyCam is maintained by [saif](https://github.com/whoissaaif) and
[Aiyan](https://github.com/Codewithaiyan). Bug reports, small fixes and discussion are welcome from anyone;
for anything bigger, open an issue first so the approach can be agreed before you spend time on it.

## Build and test

See [CLAUDE.md](CLAUDE.md) "Build and test" for the full commands. In short:

```
gradlew testDebugUnitTest    # Android unit tests (Protocol.kt, golden vectors)
gradlew lintDebug            # Android lint

cmake -S pc -B pc/build -A x64 && cmake --build pc/build --config Release
ctest --test-dir pc/build -C Release      # PC unit tests (protocol, parser, golden, transforms)
```

Both suites run in CI on every pull request (`.github/workflows/ci.yml`).

## Opening a pull request

- Branch from `main`, keep the change focused, and describe what you tested in the PR.
- **The protocol is shared.** If a change touches `protocol/PROTOCOL.md`, update it, `protocol/golden.txt`,
  `Protocol.kt` and `pc/companion/protocol.h` together — both sides are tested against the same golden
  vectors, and they'll go out of sync otherwise. Don't change the wire format without discussing it first.
- Match the existing design language (Windows XP, Luna Blue) for anything UI-facing — see
  [design/STYLE.md](design/STYLE.md). Art is generated by scripts in `design/tools/`, not hand-edited.
- "Works on every phone": don't tune behavior to one test device. See CLAUDE.md "Works on every phone" for
  the pattern (`CameraStreamer.modeFor`) if your change touches capture or encoding.
- The repo is public — don't commit screenshots, `inspo/`, signing keys/certificates, or anything with
  personal data. `.gitignore` already excludes the usual suspects.

## Reporting a bug

Open a [GitHub Issue](https://github.com/whoissaaif/mycam/issues/new/choose). Include your MyCam version,
Windows/Android version, and — if you have it — the relevant bit of the companion log
(`%LOCALAPPDATA%\MyCam\`) or the phone's `LOG` packets it copies there. Never paste device-unique
identifiers or anything from a corporate network you don't want public; this is a public repo.
